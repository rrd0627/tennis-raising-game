# 3D 캐릭터 시험

게임에는 아직 없는 시험 화면이다. 3D 캐릭터로 바꿀지 정하려고 만들었다.

- `swing.html`: 캐릭터에 손으로 짠 스윙(포핸드, 양손 백핸드, 포핸드·백핸드 발리, 서브, 스매시)을 입히고, 공 높이·거리에 맞춰 IK로 라켓 가운데를 공에 맞힌다. 확인 링크(`?check`)의 "8. 시험 중"에서 연다. `?shot=fh|bh|fv|bv|sv|sm`
  - 샷은 `SHOTS`에 정의한다: 키(몸·발·손목·라켓 방향·팔꿈치 쪽·왼손), 쥐는 법(`bevel`, 키로 바꿀 수 있음), 공의 길(`ground` `volley` `toss` `lob`), 공 종류, 발놀림. 팔꿈치 쪽은 `'auto'`로 두면 불러올 때 찾고, `rpc`/`lpc`로 주면 가슴 기준 방향(+x 왼쪽, +y 위, +z 앞)이라 몸이 돌아도 같은 쪽을 본다(양손 백핸드 피니시의 오른팔꿈치를 오른어깨 바깥 위로). `autoFace`면 줄 면도 키를 따라 이어지게 고른다.
  - 팔꿈치는 어깨-손목 축 둘레의 각(스위블, 가슴 기준)으로 키 사이를 잇는다. 'auto' 팔꿈치는 스윙 전체에서 함께 고르고(손목·어깨 부담 + 키 사이 스위블 빠르기²), 팔꿈치가 축 둘레로 휙 도는 것을 줄인다.
  - 쥐는 법: 포핸드 이스턴, 나머지는 컨티넨탈. 백핸드 쪽 샷은 반대쪽 줄 면으로 치므로 손잡이 축으로 반 바퀴 더 돈 값(-135)을 쓴다. 양손 백핸드는 준비 자세에서 왼손이 라켓 목을 돌려 쥐는 법을 바꾸고, 왼손은 손잡이 위쪽을 잡는다.
  - 팔꿈치·무릎은 경첩이라 접히는 쪽으로만 굽고 옆으로 꺾이지 않는다(위 마디가 굽는 면에 맞춰 돈다). 거의 다 펴질 때는 부드럽게 늦춘다.
  - 손목은 엎침·뒤침 ±90도, 손바닥 쪽 75·손등 쪽 70·엄지 쪽 20·새끼 쪽 30도 안으로 부드럽게 묶는다. 라켓이 가리키는 쪽은 동작대로 두고, 라켓을 그 축으로 돌린 양(줄 면이 보는 쪽)은 손목이 편한 쪽을 시간마다 미리 구해 매끈하게 잇는다(임팩트 앞뒤는 정한 면을 지킨다).
  - 손가락은 손잡이를 감아 쥔다(마디 각도는 손잡이 축에 고르게 닿게 맞춘 값). 왼손은 라켓 목을 같은 식으로 잡는다.
  - 디딘 발은 앞꿈치를 축으로 돌고, 다리가 닿지 않으면 뒤꿈치를 든다. 공이 비켜 오면 발과 몸이 먼저 옮겨 가고 남는 만큼 팔이 맞춘다.
  - 시점 '손 가까이'(`?cam=hand`)는 오른손을 따라간다.
- `jointcheck.mjs`: 관절 검사. `npm run serve`를 띄운 채 `node tools/char3d/jointcheck.mjs`. 샷마다 공 종류를 600Hz로 돌려 범위 밖 관절, 한 프레임에 튀는 곳, 팔이 갑자기 꺾이는 곳(팔꿈치가 축 둘레로 600, 위팔 800, 아래팔 1500, 굽힘 1000도/초 넘음. 스윙 안과 밖을 나눠 센다), 라켓·팔이 몸을 뚫는 곳, 디딘 발 미끄러짐, 임팩트 오차를 보여 준다(`jointcheck.js`가 페이지 안에서 잰다). 동작을 고친 뒤 돌려 본다.
- `view.html`: glb(AI 3D)나 vrm(VRoid) 모델을 원본·툰·외곽선으로 보고 경기장에 세운다. `?glb=파일&mode=studio|stadium`
- `vroid_sample.vrm`: VRoid Studio로 만든 pixiv 공식 샘플(VRM1_Constraint_Twist_Sample, © 2022 pixiv Inc.). 모델 안의 라이선스: VRM 공개 라이선스 1.0, 재배포·수정·상업 이용 허용, 표기 필요 없음. 출처: https://github.com/pixiv/three-vrm
- `models/`: 이 컴퓨터에서만 쓰는 시험 모델(커밋하지 않음)
