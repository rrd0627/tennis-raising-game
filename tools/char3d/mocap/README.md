# 모션캡처 → 3D 스윙 키

공개 모션캡처 자료를 이 게임의 스윙 키(`js/swings_mocap.js`)로 바꾸는 도구다. 사용자 요청(2026-11-11: 영상·공개 자료를 토대로 동작을 고치자)으로 만들었다.

## 자료

- Tennis-MoCap: https://github.com/jdpulgarin/Tennis-MoCap
- 콜롬비아 칼다스 지역 테니스 리그 선수 17명을 광학 모션캡처(초당 100프레임, BVH)로 찍었다. 서브, 스매시, 포핸드, 포핸드 발리, 백핸드, 백핸드 발리를 30초씩 여러 번 친다.
- 라이선스: CC BY-SA 3.0(크리에이티브 커먼즈 저작자표시-동일조건변경허락). 바꾼 키(`js/swings_mocap.js`)도 같은 라이선스로 공개하고, 게임의 ⚙️ 설정에 출처를 적는다.
- 쓰는 것: 일반 수준 여자 선수 두 명. C는 포핸드·양손 백핸드·포핸드 발리·서브·스매시, A는 한 손 백핸드 발리. 원본 파일 이름에 선수 이름이 있어 저장소에는 A·C로만 적는다.

## 하는 일

1. `convert.py`: BVH를 읽어 관절 자리와 회전을 구한다(`bvh.py`). 샷마다 여러 번 친 것 중 가장 흔한 한 번을 고른다.
   - 임팩트를 0초로 맞춘다. 땅볼은 손목이 가장 빠른 때 라켓 머리가 아직 뒤에 처져 있어서, 라켓이 네트와 나란해지는 때로 잡는다. 서브·스매시는 라켓이 가장 곧게 선 때로 잡는다.
   - 0.05초 간격으로 골반 자리와 돌기, 가슴 회전, 발(앞꿈치 자리, 발끝 방향, 뒤꿈치 각), 손목 자리와 팔꿈치 방향(가슴 기준)을 뽑는다. 라켓 방향은 손목 회전에서 얻는다.
   - 손잡이 축은 양손 백핸드에서 오른손목 → 왼손목 방향이 손목에 대해 거의 일정한 것(가운데 7~11도)으로 맞춘다. 줄 면은 임팩트 때 네트 쪽을 본다고 보고 샷마다 맞춘다. 쥐는 법은 포핸드를 세미웨스턴(-40도)으로 두고 샷마다 정한다. 그러면 서브가 컨티넨탈(+45도)에 온다.
   - 발끝 방향은 발목 회전의 옆 축으로 구하고 이어지게 편다. 팔이 거의 펴져 팔꿈치 방향을 읽을 수 없으면 이웃 값으로 메운다.
2. `run.mjs`: 스윙 화면을 화면 없이 열어 `build_keys.js`를 돌린다.
   - 골반·가슴·발은 리그 몸 크기(골반 높이 비)에 맞추고, 가슴은 실제 가슴 방향과 맞을 때까지 고친다.
   - 손목은 리그 어깨 + 가슴 방향 × (모션캡처 손목 - 어깨) × 팔 길이 비로 둔다.
   - 왼손이 라켓을 잡고 놓는 것은 0.25초쯤에 걸쳐 바뀌게 한다. 양손 백핸드 왼손을 돌려 쥐는 각(`lroll`)은 왼손목이 가장 편한 쪽으로 고른다.
   - 다 되면 `js/swings_mocap.js`를 쓴다.

## 다시 만들기

```
# 1) BVH 18개를 tools/char3d/mocap/raw/에 받는다(커밋하지 않음): C와 A의 Derecha, Reves, VDerecha, VReves, Servicio, Remate
python -I tools/char3d/mocap/convert.py      # clips.json
npm run serve                                 # 다른 창에서
node tools/char3d/mocap/run.mjs               # js/swings_mocap.js
node tools/char3d/jointcheck.mjs              # 관절 검사
```

시험 화면 '동작' 버튼으로 손으로 짠 동작과 견줘 볼 수 있다(`?src=hand`). 손으로 짠 키는 `js/swings.js`에 그대로 있고, 경기에서 기다리는 자세(준비 자세)로 쓴다.
