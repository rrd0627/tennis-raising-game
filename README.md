# 테니스 선수 키우기 (HTML5 프로토타입)

여성 직장인이 3년(78턴) 동안 2주에 한 가지씩 레슨·연습·휴식·대회를 골라 개나리부에서 국화부 우승까지 가는 육성 게임입니다.
기획 문서(Claude 문서 「테니스 선수 키우기 — 게임 디자인 문서」)를 바탕으로 만들었고, 12장의 플레이 피드백에 따라 단순화했습니다. 일정은 [로드맵](docs/ROADMAP.md)을 보세요.

**바로 플레이: https://rrd0627.github.io/tennis-raising-game/**

## 실행

ES 모듈을 쓰기 때문에 파일을 더블클릭하면 열리지 않습니다. 이 폴더에서 로컬 서버를 띄워 주세요.

```
npm run serve          # http://localhost:8080
# 또는
python -m http.server 8080
```

웹에 올릴 때는 폴더 전체를 그대로 호스팅하면 됩니다. 외부 의존성은 구글 폰트뿐이고(없으면 시스템 글꼴로 대체), three.js는 `vendor/`에 포함되어 있습니다.

## 밸런스 조정

- 경기 엔진 민감도: `js/sim.js`의 `TUNE`. 지금 값은 같은 팀끼리 50%, 능력치 +5면 승률 약 72%, +10이면 약 89%, +20이면 99%입니다.
  대회 우승에 5~6연승이 필요해서, 문서 초안(+10에 65%)보다 조금 가파르게 잡았습니다.
- 경기 전 작전: `TUNE.tempo`. 지금 값은 어느 하나로 고정해도 같은 실력에서 44~52%입니다.
- 성장 속도: `js/game.js`의 `GROWTH` (기본 9.5). 행동별 효과는 `js/data.js`의 `ACTIONS`와 `LESSONS`.
- 확인 방법:

```
npm run balance          # 능력치 차이별 승률·경기 통계, 경기 전 작전별 승률
node tools/season.js     # 3년 자동 플레이 30회 요약: 성장 곡선, 성적, 승급 시점, 엔딩, 예상 플레이 시간
```

자동 플레이 기준으로 국화 승급 중앙값은 약 110주이고, 예상 플레이 시간은 약 4시간입니다.
