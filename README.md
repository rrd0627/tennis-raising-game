# 테니스 선수 키우기 (HTML5 프로토타입)

여성 직장인이 3년(156주) 동안 일·레슨·연습·대회를 짜 넣어 개나리부에서 국화부 우승까지 가는 육성 게임입니다.
기획 문서(Claude 문서 「테니스 선수 키우기 — 게임 디자인 문서」)의 1~11장을 그대로 구현했습니다.

**바로 플레이: https://rrd0627.github.io/tennis-raising-game/**

## 실행

ES 모듈을 쓰기 때문에 파일을 더블클릭하면 열리지 않습니다. 이 폴더에서 로컬 서버를 띄워 주세요.

```
npm run serve          # http://localhost:8080
# 또는
python -m http.server 8080
```

회사 앱 웹뷰에 올릴 때는 폴더 전체를 그대로 호스팅하면 됩니다. 외부 의존성은 구글 폰트뿐이고(없으면 시스템 글꼴로 대체), three.js는 `vendor/`에 포함되어 있습니다.

## 밸런스 조정

- 경기 엔진 민감도: `js/sim.js`의 `TUNE`. 지금 값은 같은 팀끼리 50%, 능력치 +5면 승률 약 70%, +10이면 약 86%, +20이면 99%입니다.
  대회 우승에 5~6연승이 필요해서, 문서 초안(+10에 65%)보다 조금 가파르게 잡았습니다.
- 성장 속도: `js/game.js`의 `GROWTH` (기본 0.8). 월급·생활비는 `newGame()`의 `salary`, `living`.
- 확인 방법:

```
npm run balance          # 능력치 차이별 승률·경기 통계
node tools/season.js     # 3년 자동 플레이 3회: 성장 곡선, 돈, 성적, 승급 시점, 엔딩
```

자동 플레이 기준으로 국화 승급은 2년차 중반~3년차 초(85~120주)에 일어납니다.
