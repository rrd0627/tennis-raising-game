# 우마무스메와 비교한 남은 일

우마무스메에는 있는데 아직 안 넣었거나 일부만 넣은 것을 모두 적는다. **결국 전부 만든다(사용자 결정, 2026-11-05).** 하나씩 만들 때마다 표에서 ☐를 ☑로 바꾼다.

- 비교 기준: 조사 보고서(`reports/우마무스메 시스템 연계 구조.md`, 저장소 밖)와 2026-11-05 시점의 코드.
- 한계: 근거가 팬 위키와 공략이고 게임 안에서 직접 확인한 값이 없다. 홈 메뉴 전체를 적은 자료도 못 찾아서 빠진 항목이 더 있을 수 있다.
- 묶음 이름과 사용자 답은 `docs/SYSTEMS.md`. 테니스 내용은 지어내지 않고 사용자에게 물어 만든다.
- 순서는 플레이어가 만나는 순서를 따른다. 흐름 차이를 먼저 맞추고, 그다음 일부만 넣은 것, 마지막으로 판 사이와 판 밖이다.

## 1. 게임 흐름의 차이

시스템은 있어도 플레이 흐름이 다른 부분이다.

| 상태 | 때 | 우마무스메 | 우리 | 할 일 |
| --- | --- | --- | --- | --- |
| ☐ | 판 시작 전 | 캐릭터, 부모, 서포트 카드를 고르고 시작 | 코치와 대화 후 바로 첫 레슨 | 2회차부터 준비 화면 (묶음 F, G) |
| ☐ | 첫 턴들 | 훈련 칸이 처음부터 모두 열려 있음 | 레슨뿐이고 17주쯤 모두 열림 | 사용자가 정한 설계라 유지. 2회차부터는 처음부터 열지 판단 |
| ☐ | 턴 결과 | 짧은 연출 뒤 바로 다음 턴. 한 판 20~40분(출처별로 13분~1시간) | 턴마다 약 3.8단계를 눌러 넘김. 한 판 약 4시간(추정) | 2회차 빨리 감기와 함께 재검토. 사용자가 단계 진행을 정했으므로 줄이기 전에 확인 |
| ☐ | 이벤트 | 턴 끝에 일정 확률. 확률 수치는 못 찾음 | 턴의 68%에 끼어들고 33%는 두 개 이상. 3년에 초대만 18번 | 초대 빈도부터 줄임 |
| ☑ | **목표** | 정해진 경주에서 몇 등 안, 또는 기한까지 팬 수 | 정해진 대회에서 몇 강 안. 그 턴에는 그 대회만 | 완료 (11/5). 팬 수 조건은 아직 없음 |
| ☑ | **목표 실패** | 그 경주에서 지는 순간. 알람 시계로 그 경주만 다시 | 그 대회에서 지는 순간. 같은 상대와 그 경기만 다시, 기회 3번 | 완료 (11/5) |
| ☐ | **대회의 무게** | 경주 턴마다 경주 1번 | 대회 1번에 평균 4.3경기. 3년에 74경기, 그중 중계 46경기 | 경기 수와 중계 범위 재검토 |
| ☐ | 대회 고르기 | 여러 경주 중에 고름. 팬 수로 자격이 열림 | 대회마다 성격이 있고 일부 턴에 두 대회. 파트너가 거절하면 못 나감 | 대회 수를 늘릴지, 인맥으로 자격을 열지 남음 |
| ☐ | 경기 직전 | 경주 준비 전까지 스킬 구매 가능 | 기술은 주간 화면에서만 배움 | 대회 첫 화면에 기술 버튼 |
| ☐ | 판 끝 | 스파크 결정, 완성 캐릭터 저장, 다른 모드로 이어짐 | 최종 평가 후 새로 시작뿐. 남은 경험 중앙값 111은 그대로 사라짐 | 묶음 F. 끝나기 전 남은 경험 쓰기(우마무스메에서 그런 화면을 본 기억은 있으나 자료로 확인 못 함) |

우리에게만 있는 것: 파트너 구하기와 거절, 랭킹과 시드, 포인트 소멸, 회사 이벤트와 야근, 메신저, 정체기와 계단, 레슨 주제 고르기, 대회 성격과 선수풀.

요정과 주인공에서 더 할 일: 요정 그림, 이름과 말투, 회사 이벤트 선택지를 요정 시점으로 고치기, 장면 글에서 주인공 혼잣말과 요정에게 하는 말 나누기.

선수풀에서 더 할 수 있는 것: 랭킹 표를 실제 선수 이름으로 보여 주기, 대회에서 만난 선수를 인맥으로 얻어 파트너로 부르기, 라이벌을 선수풀에서 고르기.

## 2. 일부만 넣은 것

| 상태 | 시스템 | 있는 것 | 빠진 것 |
| --- | --- | --- | --- |
| ☐ | 서포트 카드 | 칸 배치, 인원 보너스, 특기 칸 | 판 전 편성(지금은 아는 사람이 전부 나옴), 6명 제한, 돌파, 카드 등급과 강화 |
| ☐ | 사람별 이벤트 | 2단계 이야기 | 3~5단계 연속 이벤트, 명단 밖 사람 이벤트, 사람과 함께 가는 외출 |
| ☐ | 스킬 | 4개, 2단계, 힌트 할인 | 조건부 발동, 상대의 기술, 방해 스킬, 빠른 학습 상태 |
| ☐ | 컨디션 | 좋은 상태 3개, 나쁜 상태 4개, 슬럼프 | 더 다양한 상태, 무작위 손실 |
| ☐ | 경주 | 대회, 보상, 약점 | 연속 출전 벌칙 |
| ☐ | 팬 | 인맥이 수락과 초대를 늘림 | 출전 자격, 목표 조건에 인맥 넣기 |
| ☐ | 훈련 실패 | 효과 감소, 기분 하락, 멘탈, 입스, 부상 | 능력치 손실 |
| ☐ | 전리품 | 상품이 쌓임 | 쓸 곳 (묶음 G의 각성) |
| ☐ | 시나리오 | 기본형 1개 | 전용 자원, 추가 시나리오 |
| ☐ | 재도전 | 기회 3번, 기한 연장 | 다시 하면 기분이 오르는 효과, 그 경기만 다시 하기 |
| ☐ | 적성 | 코트와 상대의 공 | 작전 적성 |
| ☐ | 판 밖 이야기 | 엔딩 12개 | 다시 보기, 사람별 앨범 |
| ☐ | 능력치 | 등급과 볼록한 평가 곡선 | 시나리오나 계승으로 올라가는 능력치 상한 |

## 3. 아직 없는 것: 판과 판 사이 (묶음 F)

| 상태 | 시스템 | 하는 일 |
| --- | --- | --- |
| ☐ | 주인공 명단(캐릭터) | 판마다 요정이 새 사람에게 간다. 사람마다 소원, 잘 늘어나는 쪽, 익숙한 것, 자기 목표, 일상 이벤트, 결말이 다르다 |
| ☐ | 완성 캐릭터 저장 | 끝난 판의 선수를 남긴다. 지금은 저장이 하나뿐이고 새로 시작하면 지워진다 |
| ☐ | 스파크 | 판이 끝날 때 다음 판에 물려줄 것이 정해진다 |
| ☐ | 계승 | 물려받은 것이 판 시작과 2, 3년차 봄에 발동한다 |
| ☐ | 친화도 | 조합에 따라 더 잘 물려받는다 |
| ☐ | 부모 대여 | 다른 사람의 캐릭터를 빌린다 |
| ☐ | 별(재능 개화) | 기본 능력치와 등급을 영구히 올린다 |
| ☐ | 각성 | 재료를 써서 다음 판에 배울 스킬 후보를 늘린다 |
| ☐ | 계정 유대 레벨 | 완주할수록 쌓여 이야기가 열린다 |

| ☐ | 프리미엄 재화 | 활동 보상이 모여 가챠로 간다. 결제 없이 게임 안에서만 얻는다 |
